# Amharic Bible — Mobile (Flutter)

The native mobile client. Same **Supabase** backend and **Bible content API** as
the web app (`../web`). Built with the "Illuminated Devotional" aesthetic.

## Stack
- **Flutter 3.44** / Dart 3.12
- `supabase_flutter` — auth, Postgres, **realtime**, storage
- `http` — Amharic Bible content API (native, no CORS needed)
- `google_fonts`, `image_picker`, `share_plus`, `shared_preferences`, `intl`

## Run
```bash
cd mobile
flutter pub get
flutter run            # on a connected device or emulator
```
Config lives in `lib/config.dart` (the Supabase anon key is a public client key).

## Implemented
- **Auth** — email/password → username onboarding
- **Home** — daily verse, today's full chapter, reading streak, mark-as-read
- **Reader** — books → chapters → verses; tap a verse to share (friend/copy/system)
- **Chat** — conversation list (realtime) + thread with verse bubbles, streak, composer
- **Friends** — list, received/sent requests, username search + add
- **Profile** — avatar upload, name/username edit, stats, theme/serif/size, sign out

## Notes
- Uses the same Supabase project as web (run the same SQL migrations in ../web/supabase/).
- Daily verse + chapter read from DB (generated by the web cron); curated fallback otherwise.
